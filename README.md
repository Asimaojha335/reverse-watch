# Reverse Watch (Countdown Timer)

A countdown timer built with HTML, CSS, JavaScript and Bootstrap.

- Set hours, minutes and seconds, or use the quick presets (1, 5, 10, 25 minutes)
- Start, pause, resume and reset
- Ring that drains as time runs out, and the time in the browser tab title
- A three-beep alarm when time is up (made with the Web Audio API, no audio file)
- Keyboard shortcuts: `Space` start/pause, `R` reset
- Light and dark theme, responsive

Open `index.html` in a browser. No build step is needed.
